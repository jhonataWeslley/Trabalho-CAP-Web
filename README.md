**Projeto Front-end vs Back-end**

Descrição
Este projeto demonstra, de forma prática, a comunicação entre front-end e back-end em uma aplicação web simples.
O sistema permite que o usuário digite um nome, envie para o servidor e receba uma resposta exibida na tela.

Tecnologias utilizadas:
- HTML
- JavaScript
- Node.js
- Express

Como executar o projeto:
1. Clonar ou baixar o projeto
2. Instalar as dependências (na pasta backend)
bash
npm install
